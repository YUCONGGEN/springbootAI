# Security Policy

## Supported Versions

Security fixes are provided for the latest released minor version. Older versions
should be upgraded before reporting an issue.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting flow for this repository and include affected versions,
reproduction steps, impact, and any known mitigations.

The maintainers will acknowledge a complete report within five business days and
will coordinate disclosure after a fix is available. Never include production
credentials, customer data, or active access tokens in a report.
